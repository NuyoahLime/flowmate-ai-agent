# FlowMate MVP Scope

本文档记录 FlowMate 第一版 MVP 范围。当前阶段只记录场景和工具规划，不实现 Agent、Tool、LLM、LangGraph、数据库、Redis、前端或真实第三方 API。

## MVP 场景

### 场景 1

“我明天早上八点半在公司开会，帮我安排好明早出门。”

### 场景 2

“我晚上七点到家，提前把家里准备好。”

### 场景 3

“今晚孩子回家后，把家里调整成适合学习的状态。”

## 第一版计划支持的工具

- calendar_tool
- navigation_tool
- weather_tool
- smart_home_tool
- vehicle_tool
- notification_tool

## 阶段 1 约束

当前阶段只记录工具名称和项目规划，不实现任何 Tool 行为。
